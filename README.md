# Lakehouse Quiz

A Jeopardy-style quiz app built with Vue.js, themed for Barun's birthday-eve quiz night (27 May @ LakeHouse).

## Categories

Fifa Fufa · Plot Twist · On The Rocks · Bhukkad Kukkad · Boll-emoji — 5 questions each (10–50 points).

## Setup

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

Output goes to `dist/`.
